Aquarium TinyML Gateway – Hướng dẫn chạy
========================================

Tổng quan
---------
Tài liệu này mô tả cách chuẩn bị môi trường và khởi động đủ ba API: Dashboard (Flask), Gateway thu thập (Flask) và Gateway ML (FastAPI có Swagger UI). Root `/` của gateway ML không có handler nên truy cập trực tiếp sẽ trả `{"detail":"Not Found"}` – hãy dùng `/docs`.

Chuẩn bị chung
--------------
1. Cài Python 3.11+ (3.12 chạy tốt).
2. Clone repo rồi `cd aquarium-tinyml`.
3. Tuỳ chọn: sao chép `.env.example` → `.env` nếu cần đổi port/đường dẫn.
4. Để khỏi nhớ lệnh pip dài, có thể chạy `python install_dependencies.py` (thêm `--gateway` nếu chỉ cài phần API).
5. `requirements.txt` dùng environment marker nên hoạt động chung cho macOS/Windows; nếu thích tách riêng thì vẫn có `requirements-macos.txt` và `requirements-windows.txt`.

macOS (zsh/bash)
----------------
1. Tạo virtualenv: `python3.11 -m venv .venv`.
2. Kích hoạt: `source .venv/bin/activate`.
3. Nâng cấp pip + cài phụ thuộc: `python -m pip install --upgrade pip` rồi `pip install -r requirements-macos.txt` (hoặc `requirements.txt`).

Windows (PowerShell)
--------------------
1. Tạo virtualenv: `py -3.11 -m venv .venv`.
2. Kích hoạt: PowerShell → `.\.venv\Scripts\Activate.ps1` (nếu bị chặn hãy chạy `Set-ExecutionPolicy -Scope Process RemoteSigned`); CMD → `.\.venv\Scripts\activate.bat`.
3. Nâng cấp pip + cài phụ thuộc: `python -m pip install --upgrade pip` rồi `pip install -r requirements-windows.txt` (hoặc giữ `requirements.txt` dùng chung).

Khởi động 3 dịch vụ API
-----------------------
Đảm bảo mỗi tiến trình chạy ở tab terminal riêng để có log độc lập. Nếu muốn gom cả ba vào một câu lệnh (chạy song song, tự dừng khi nhấn Ctrl+C) thì dùng script `python tools/run_stack.py` (có thể truyền thêm `--dashboard-port`, `--gateway-port`, `--ml-port` nếu muốn đổi port). Lúc đó bạn vẫn thấy log của từng service lẫn trong một terminal.

1. **Dashboard (Flask)**
   - Port mặc định: `3000` (có thể đổi qua biến `DASHBOARD_PORT`).
   - Lệnh: `python dashboard/app.py`.
   - Mở giao diện tại `http://127.0.0.1:<port>/`.

2. **Gateway thu thập (Flask – src/gateway/main)**
   - Port mặc định: `5001` (biến `GATEWAY_MAIN_PORT`).
   - Lệnh: `python src/gateway/main/app.py`.
   - Các endpoint `/api/...` nhận dữ liệu turbidity, temperature/humidity, water và trả JSON.

3. **Gateway ML (FastAPI – src/gateway/ml)**
   - Port mặc định: `5000` (biến `ML_API_PORT`).
   - Lệnh: `python src/gateway/ml/app.py` (chạy uvicorn với hot reload).
   - Swagger UI tại `http://127.0.0.1:<port>/docs`, Redoc tại `/redoc`.

Tips:
- Nếu muốn docker hoá gateway thu thập, dùng `cd src/gateway/main && docker-compose up --build`.
- File `install_dependencies.py` vẫn hữu ích khi muốn cài nhanh `requirements-base.txt` (tùy chọn `--gateway`).
- Script `python tools/run_stack.py` giúp khởi động cả ba service cùng lúc; nhấn Ctrl+C để dừng toàn bộ.

Chạy riêng training pipeline (CMD/Terminal)
------------------------------------------
- Đảm bảo dataset đã được tạo (`dataset/interim/...`). Nếu thiếu có thể chạy chuỗi script trong `src/ml/train` (ingest → weak_label → preprocess → features).
- Khi chỉ cần huấn luyện lại model: `python src/ml/train/train_core.py` (đang đọc config mặc định trong file).
- Các bước hậu xử lý (quantize, export header) có thể chạy thủ công qua `python src/ml/train/quantize.py` và `python src/ml/train/export_header.py`.

Full flow thu thập → ML → training → push kết quả
-------------------------------------------------
1. **Gateway Main gom dữ liệu 10 phút một lần** (hiện tại lấy từ DB, sau này chuyển sang nguồn realtime). Ví dụ:
   ```bash
   curl "http://127.0.0.1:5001/api/telemetry/export?minutes=10&dataset_type=train_live" -o /tmp/bundle.json
   ```
   Hoặc gửi trực tiếp sang Gateway ML (không qua file):
   ```bash
   curl -X POST http://127.0.0.1:5000/ingest/gateway-sample \
     -H "Content-Type: application/json" \
     -d '{"device_id":"gateway-01","temperature":28.5,"humidity":76,"turbidity_raw":510,"turbidity_ntu":4.2,"water_value":1234,"ph":7.1,"timestamp":"2025-01-01T12:00:00"}'
   ```
   → ML sẽ append vào `dataset/gateway/gateway_samples.csv` và log JSONL để debug.

2. **Chạy training kết hợp dataset label + gateway** (tham số giống JSON mẫu, có thể chỉnh bằng flag). Ví dụ:
   ```bash
   python src/ml/train/train_core.py \
     --input-file dataset/interim/aquarium_tinyml_features.csv \
     --extra-dataset dataset/gateway/gateway_samples.csv \
     --model-out ml/artifacts/aquarium_classifier.keras \
     --metrics-out ml/artifacts/aquarium_classifier_metrics.json \
     --label-encoder-out ml/artifacts/label_encoder.joblib \
     --epochs 125 --batch-size 64 --val-size 0.15 --test-size 0.15 --random-state 42 \
     --push-adjustment-url http://127.0.0.1:5001/api/model/adjustment \
     --pond-id pond-01 --model-id aquarium_v1
   ```
   Nếu không muốn push kết quả tự động thì bỏ 3 flag cuối (`--push-adjustment-url`, `--pond-id`, `--model-id`).

3. **Xem log/metrics**: logging nằm ở `ml/training_logs/*.log`, metrics JSON tại `ml/artifacts/aquarium_classifier_metrics.json`, run snapshot tại `ml/artifacts/runs/<timestamp>/`.

4. **Kết quả training sẽ POST về Gateway Main** (hoặc tự gọi):
   ```bash
   curl -X POST http://127.0.0.1:5001/api/model/adjustment \
     -H "Content-Type: application/json" \
     -d @ml/artifacts/aquarium_classifier_metrics.json
   ```
   (payload thực tế sẽ là kết quả train_core gửi với đầy đủ thông tin model/metrices). Gateway Main log lại tại `dataset/live_exports/adjustment_results.jsonl`. ESP32 có thể đọc lệnh từ các API `/api/...` hiện hữu hoặc endpoint `api/gateway/command`.

Checkpoint & log phục vụ tinh chỉnh
------------------------------------
- **Checkpoint model**: sau mỗi lần train, toàn bộ snapshot nằm trong `ml/artifacts/runs/<timestamp>-<suffix>/` (gồm model `.keras`, metrics, history). Chỉ cần copy folder này để giữ “bản tốt nhất”.
- **Log job**: `ml/training_logs/*.log` chứa console output, file `_epochs.json` ghi thời gian từng epoch để so sánh giữa các run.
- **Metrics chính thức**: `ml/artifacts/aquarium_classifier_metrics.json` luôn lưu classification report, confusion matrix, class weights → chính là payload gửi sang Gateway Main.
- **Bản ghi gửi Gateway Main**: mỗi lần `/api/model/adjustment` nhận payload sẽ:
  1. Append JSONL vào `dataset/live_exports/adjustment_results.jsonl`.
  2. Ghi một file chi tiết `dataset/live_exports/log_result/log_result_<timestamp>.json` (timestamp giờ VN) giúp audit/rollback và làm checkpoint tinh chỉnh hồ nước.
- Từ log_result có thể map ngược về run folder tương ứng (dựa vào `model_id`/`metrics_file`) để tải lại model hoặc điều chỉnh threshold theo yêu cầu.

Troubleshooting
---------------
- `{"detail":"Not Found"}`: bạn mở root `/` của FastAPI; hãy dùng `/docs` hoặc `/health`.
- Thiếu package (vd. `uvicorn`, `Flask`): kiểm tra virtualenv đã kích hoạt và cài đúng `requirements-*.txt`.
- Lỗi cổng bận: đổi port bằng biến môi trường tương ứng hoặc truyền `--port` cho uvicorn.
- TensorFlow lỗi khi dùng Python <3.11: tạo lại virtualenv bằng Python 3.11+.

Ghi chú bổ sung
---------------
- Các script training trong `src/ml/train` cần dataset ở `dataset/interim`. Nếu thiếu, hãy chạy pipeline ingest → weak_label → preprocess → features trước.
- Dòng cuối của mỗi app (Flask/FastAPI) đọc biến môi trường để không trùng port, nên khi deploy nhớ cấu hình `.env` hoặc systemd service tương ứng.
